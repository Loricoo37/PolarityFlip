# PolarityFlip

A simple stereo VST3 audio plugin built with JUCE.

## Features

- Left / Right polarity inversion
- Independent Left / Right gain
- Haas effect
- Hasser bypass switch
- Parameter state saving
- Custom GUI

## Built With

- C++
- JUCE 9.0.3
- Visual Studio 2026

## Status

Early development / learning project.
